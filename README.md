# ROYAL LUDO 👑

A complete, production-grade online multiplayer Ludo game built with TypeScript, React, Node.js, and PostgreSQL.

## Overview

**Royal Ludo** is a sophisticated, mobile-first online Ludo game featuring:

- ✅ 2-player and 4-player online matches
- ✅ Quick matchmaking and private rooms
- ✅ Room codes and invite/share functionality
- ✅ Reconnection with state recovery
- ✅ Turn timers and complete match lifecycle
- ✅ Player profiles with statistics
- ✅ ELO-based rankings
- ✅ Original royal branding
- ✅ Responsive mobile and desktop UI
- ✅ Server-authoritative game engine
- ✅ WebSocket real-time multiplayer
- ✅ Secure authentication
- ✅ Comprehensive testing

## Tech Stack

- **Frontend**: React 18, TypeScript, Vite, TailwindCSS, Zustand
- **Backend**: Node.js, Express, WebSocket (ws), Prisma
- **Database**: PostgreSQL 15+
- **Testing**: Vitest, Jest, deterministic simulation
